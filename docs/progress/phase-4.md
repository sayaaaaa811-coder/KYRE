# Phase 4 完了報告：返信文生成

- 完了日: 2026-10-13
- ブランチ: `claude/kyre-schedule-dev-nfmsj6`

## 1. 実装内容

### 使い方（最短 4 タップ）
貼り付け →「候補を抽出する」→「空き状況を確認する」→ **「返信文をコピー」** → LINE に貼り付け

| 画面 | できること |
|---|---|
| ③ 照合結果 | 結果のすぐ下に **返信文のプレビュー**。文体（カジュアル／丁寧）の切り替え、**代替案のチップをタップすると返信文に追加**（もう一度タップで外す） |
| ④ 返信文の編集 | 「返信文を編集」から、自由に書き換えてコピー。「自動作成の文に戻す」で元に戻せる |
| コピー | 成功時「コピーしました。LINEに戻って貼り付けてください」と表示。コピーできない環境では長押しでのコピーを案内 |

### 返信文の作り方（`src/lib/reply/`）
- AI は使わず、**テンプレートで端末内で作成**（費用なし・本文の外部送信なし）。メッセージ本文は使わず、日時と判定結果だけから作ります。
- 自然な表記の工夫:
  - 同じ月が続くときは月を省略（`10/20(火)・21(水)`）
  - 同じ時刻の日はまとめる（`10/20(火)・21(水)の19時〜`）
  - カジュアルは `19時〜` `18時半〜`、丁寧は `19:00〜`
- 初期の代替案の選び方: 参加できる候補が 1 つもないときだけ、各候補の最も近い代替案を自動で選択（参加できる日があるときは、余計な提案をしない）
- 判定対象外（過去・日付またぎ）の候補は返信に含めません
- **予定を取得できなかった候補が 1 つでもあれば返信文は作りません**（誤った返信を防ぐため）

### 文例

| 状況 | カジュアル | 丁寧 |
|---|---|---|
| 参加可能 | 誘ってくれてありがとう！<br>10/19(月)の19時〜なら行けるよ！<br>楽しみにしてる！ | ご連絡ありがとうございます。<br>10/19(月) 19:00〜でしたら参加可能です。<br>よろしくお願いいたします。 |
| 一部不可 | …<br>20(火)は予定があって難しそう… | …<br>20(火)は予定があり、参加が難しい状況です。 |
| 代替案を選択 | 20(火)は19時だと難しいけど、20:15〜なら大丈夫！ | 20(火)は19:00からは難しいのですが、20:15〜でしたら調整可能です。 |
| すべて不可 | ごめん、その日程だと都合が合わなくて…別の日でも大丈夫？ | 申し訳ありません、ご提示いただいた日程はいずれも都合がつかず…別の日程をご相談させていただけますでしょうか。 |

## 3. 動作確認方法

1. `npm run dev` → <http://localhost:3000/?mock=mixed>（デモ）またはGoogle連携で
2. `来週どこか飲みに行こう！ 10/19(月)か20(火)の19時〜どう？` のような文を貼り付けて進む
3. 結果画面で返信文を確認 → 代替案のチップをタップ → 文体を切り替え → 「返信文をコピー」
4. LINE やメモアプリに貼り付けて内容を確認
