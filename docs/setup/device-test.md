# 実機確認チェックリスト（iPhone / Android）

自動テストは Chromium（Chrome 系）で iPhone・Android の画面サイズを再現しています。iPhone の Safari では表示や動作が異なることがあるため、限定公開の前に実機で確認してください。

## 準備

- パソコンでアプリを起動しているだけでは、スマートフォンから開けません（`localhost` はそのパソコン自身を指すため）。
- **実機確認は、限定公開用の URL にデプロイした後に行うのが簡単です**（デプロイには承認が必要です。docs/setup/deploy.md）。

## 確認項目

| # | 操作 | 期待される結果 | iPhone | Android |
|---|---|---|---|---|
| 1 | LINE でメッセージを長押し→コピーし、アプリの入力欄を長押し→ペースト | 貼り付けられる | ☐ | ☐ |
| 2 | 「クリップボードから貼り付け」ボタン | 貼り付けられる（iPhone は「ペースト」の確認が出る） | ☐ | ☐ |
| 3 | 「候補を抽出する」 | 候補が表示される。文字が小さすぎない・画面がズームしない | ☐ | ☐ |
| 4 | 候補の日付・時刻をタップして変更 | 日付・時刻の選択画面が開き、変更が反映される | ☐ | ☐ |
| 5 | 「空き状況を確認する」→ Google で連携 | Google の画面 → 許可 → アプリに戻り、結果が自動で表示される | ☐ | ☐ |
| 6 | 自分の予定がある日時・ない日時 | 正しく「予定があります」「参加できます」になる | ☐ | ☐ |
| 7 | 代替案のチップをタップ | 返信文に追加される | ☐ | ☐ |
| 8 | 「返信文をコピー」→ LINE に貼り付け | 返信文がそのまま貼り付けられる | ☐ | ☐ |
| 9 | 「返信文を編集」で書き換えてコピー | 書き換えた文がコピーされる | ☐ | ☐ |
| 10 | 端末の「戻る」操作（iPhone は画面左端から右へスワイプ） | 前のステップに戻り、入力内容が残る | ☐ | ☐ |
| 11 | 下部のボタン | 画面下の黒いバー（ホームバー）と重ならない | ☐ | ☐ |
| 12 | メニュー（≡）→ 設定 →「連携を解除する」 | 解除される。次の照合で再度連携を求められる | ☐ | ☐ |
| 13 | 機内モードで「空き状況を確認する」 | 「インターネットに接続できませんでした」と表示され、「参加できます」は表示されない | ☐ | ☐ |

気になる点があれば、スクリーンショットと「何番の項目か」を送ってください。
