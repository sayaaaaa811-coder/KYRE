# Google カレンダー連携の設定手順（初心者向け）

KYRE Schedule をあなたの Google カレンダーと連携させるための設定です。所要時間は 15〜20 分ほどです。

> **大切なこと**
> - この手順で **費用は発生しません**。Google Calendar API は無料で使えます。途中で「請求先アカウント（クレジットカード）」の登録を求められた場合は、**登録せずに手を止めて** ご連絡ください。
> - 途中で表示される **クライアント シークレット** は、パスワードと同じくらい大切な情報です。チャット・メール・GitHub などに貼り付けないでください。
> - Google の画面は時々デザインが変わります。ボタンの名前が少し違う場合は、近い名前のものを選んでください。迷ったら画面のスクリーンショットを送ってください（シークレットが写っていないことを確認してから）。

---

## 1. Google Cloud にログインする

1. パソコンのブラウザで <https://console.cloud.google.com/> を開きます。
2. カレンダーを連携したい Google アカウントでログインします。
3. 初めての場合は利用規約が表示されるので、国「日本」を選んで同意します。

## 2. プロジェクトを作る

1. 画面上部の「プロジェクトを選択」（またはプロジェクト名が表示されている部分）をクリックします。
2. 「新しいプロジェクト」をクリックします。
3. プロジェクト名に `KYRE Schedule` と入力し、「作成」をクリックします。
4. 作成が終わったら、画面上部で `KYRE Schedule` が選択されていることを確認します。

## 3. Google Calendar API を有効にする

1. 左上の「≡」メニュー →「API とサービス」→「ライブラリ」を開きます。
2. 検索欄に `Google Calendar API` と入力し、表示された「Google Calendar API」をクリックします。
3. 「有効にする」をクリックします。

## 4. 同意画面（アプリの情報）を設定する

1. 左上の「≡」メニュー →「API とサービス」→「OAuth 同意画面」を開きます。
   （「Google Auth Platform」という画面が開く場合もあります。同じものです）
2. 「開始」または「構成を開始」をクリックし、次のように入力します。
   - **アプリ名**: `KYRE Schedule`
   - **ユーザー サポートメール**: あなたのメールアドレス
   - **対象（ユーザーの種類）**: **外部**
   - **連絡先情報**: あなたのメールアドレス
3. ポリシーに同意して「作成」をクリックします。

## 5. 使う権限（スコープ）を登録する

1. 同じ画面の左メニューから「データアクセス」を開きます。
2. 「スコープを追加または削除」をクリックします。
3. フィルタ（検索欄）に `calendar.freebusy` と入力します。
4. `https://www.googleapis.com/auth/calendar.freebusy`（説明: カレンダーの空き時間情報の表示 など）に **チェックを入れて**「更新」をクリックします。
5. 画面下の「保存」をクリックします。

> この権限で取得できるのは「予定がある時間帯」だけです。予定の名前・場所・参加者は取得できません。

## 6. テストユーザーを登録する

アプリは「テスト中」の状態で使います（Google の審査前でも、登録した人だけが使えます。最大 100 人）。

1. 左メニューから「対象」を開きます。
2. 公開ステータスが「**テスト中**」になっていることを確認します（「アプリを公開」は押さないでください）。
3. 「テストユーザー」の「ユーザーを追加」をクリックし、あなたの Gmail アドレスを入力して「保存」します。

## 7. クライアント ID とシークレットを作る

1. 左メニューから「クライアント」を開き、「クライアントを作成」をクリックします。
2. 次のように入力します。
   - **アプリケーションの種類**: ウェブ アプリケーション
   - **名前**: `KYRE Schedule (local)`
   - **承認済みのリダイレクト URI**: 「URI を追加」をクリックし、次を **一字一句そのまま** 入力
     ```
     http://localhost:3000/api/auth/google/callback
     ```
   - 「承認済みの JavaScript 生成元」は空欄のままで構いません。
3. 「作成」をクリックします。
4. **クライアント ID** と **クライアント シークレット** が表示されます。
   - 「JSON をダウンロード」ボタンがあれば、ダウンロードしてパソコンの安全な場所に保存してください（シークレットは後から再表示できない場合があります）。

## 8. パソコンに設定ファイル（.env.local）を作る

1. ターミナルで KYRE のフォルダに移動します（README の手順で `cd KYRE` した場所）。
2. 次のコマンドで、セッション暗号化用の鍵を作ります。表示された文字列をコピーします。
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
   ```
3. フォルダ内の `.env.example` をコピーして `.env.local` という名前のファイルを作ります。
   ```bash
   cp .env.example .env.local
   ```
   （Windows の PowerShell では `Copy-Item .env.example .env.local`）
4. `.env.local` をテキストエディタ（メモ帳、VS Code など）で開き、次のように埋めて保存します。
   ```
   GOOGLE_CLIENT_ID=（手順7のクライアント ID）
   GOOGLE_CLIENT_SECRET=（手順7のクライアント シークレット）
   GOOGLE_REDIRECT_URI=http://localhost:3000/api/auth/google/callback
   SESSION_SECRET=（手順8-2で作った文字列）
   APP_ORIGIN=http://localhost:3000
   ```
   `=` の前後に空白を入れないでください。

## 9. 動作確認

1. ターミナルで `npm run dev` を実行し、ブラウザで <http://localhost:3000> を開きます。
   （すでに起動していた場合は `Ctrl + C` で止めてから再度起動してください。設定ファイルは起動時に読み込まれます）
2. 日程のメッセージを貼り付け →「候補を抽出する」→「空き状況を確認する」を押します。
3. 「Googleで連携する」を押すと Google の画面が開きます。
   - 「**このアプリは Google で確認されていません**」と表示されます。テスト中のため正常です。「詳細」→「KYRE Schedule（安全ではないページ）に移動」を押します。
   - 権限の確認画面では、**カレンダーの項目にチェックが入っていること** を確認して「続行」を押します。
4. KYRE に戻り、あなたのカレンダーの予定に基づいた結果が表示されれば成功です。
5. 右上のメニュー（≡）→「設定」から、いつでも連携を解除できます。

## うまくいかないとき

| 表示 | 原因と対処 |
|---|---|
| 「Google連携は準備中です」と出る | `.env.local` が読み込まれていません。ファイル名・場所（KYRE フォルダの直下）・`=` の前後の空白を確認し、`npm run dev` を再起動してください。ターミナルに `config_invalid` と表示されていれば、その後ろに不正な項目名が出ています |
| Google の画面に「エラー 400: redirect_uri_mismatch」 | 手順 7 のリダイレクト URI が `http://localhost:3000/api/auth/google/callback` と完全に一致しているか確認してください（末尾の `/` や `https` に注意） |
| 「エラー 403: access_denied」 | 手順 6 のテストユーザーに、ログインしたアカウントが登録されていません |
| 「カレンダーの空き状況へのアクセスが許可されませんでした」 | 権限確認画面でカレンダーのチェックが外れていました。もう一度連携してチェックを入れてください |

## シークレットを漏らしてしまったら

Google Cloud の「クライアント」画面で該当のクライアントを開き、シークレットを再発行（または古いシークレットを無効化）し、`.env.local` を新しい値に更新してください。
