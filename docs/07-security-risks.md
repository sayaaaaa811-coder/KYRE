# 07. セキュリティリスク一覧

評価: 影響度・発生可能性ともに 高 / 中 / 低。

| # | リスク | 影響 | 可能性 | 対策 | 確認方法 |
|---|---|---|---|---|---|
| S01 | **OAuth CSRF**（攻撃者の認可コードで被害者を連携させる） | 中 | 中 | 32 バイト乱数 state を暗号化一時 Cookie と定数時間比較、1 回限り、10 分失効 | state 不一致・欠落・再利用で 400 になるテスト |
| S02 | **認可コード横取り** | 高 | 低 | PKCE（S256）、redirect_uri 完全一致、client_secret はサーバーのみ | code_verifier なしで交換失敗することを確認 |
| S03 | **アクセストークン漏洩**（ブラウザ・ログ・URL） | 高 | 中 | 暗号化 HttpOnly Cookie、トークンをレスポンス本文・URL に含めない、ログ許可リスト、リフレッシュトークン不取得で被害を約 1 時間に限定 | レスポンス・ログ・HTML にトークン文字列がないことを自動テスト |
| S04 | **client_secret / SESSION_SECRET の漏洩** | 高 | 低 | 環境変数管理、`NEXT_PUBLIC_` 禁止、`server-only`、`.env*` を Git 除外、GitHub のシークレットスキャン | ビルド成果物（`.next/static`）に秘密値が含まれないか検査 |
| S05 | **過剰な権限** | 中 | 低 | `calendar.freebusy` のみ要求、付与スコープを検証、メール等は取得しない | 同意画面の表示確認 |
| S06 | **API への CSRF**（他サイトから freebusy や disconnect を呼ぶ） | 中 | 中 | SameSite=Lax、Origin 検証、JSON + 独自ヘッダー必須、状態変更は POST のみ | 不正 Origin で 403 のテスト |
| S07 | **XSS**（貼り付けたメッセージ経由のスクリプト実行） | 高 | 低 | React の自動エスケープ、`dangerouslySetInnerHTML` 禁止（Lint）、nonce 付き厳格 CSP | `<script>` 等を含む入力の E2E |
| S08 | **クリックジャッキング** | 低 | 低 | `frame-ancestors 'none'`、`X-Frame-Options: DENY` | ヘッダーのテスト |
| S09 | **ReDoS / 巨大入力による DoS**（正規表現の暴走） | 中 | 中 | 入力 2,000 文字上限、正規表現は入れ子の量指定子を避ける、処理時間テスト | 病的入力で 50ms 以内のテスト |
| S10 | **API 乱用**（Google クォータ枯渇・コスト） | 中 | 中 | レート制限、入力検証（範囲 10 件・各 1 日以内・90 日以内）、5 秒タイムアウト | 制限超過で 429 のテスト |
| S11 | **「空き」の誤表示**（取得失敗・タイムゾーン誤り・終日予定の見落とし） | 高 | 中 | 取得失敗は空き扱いしない、レスポンス厳密検証、全時刻を絶対時刻で計算、終日・境界のテスト | matcher / freebusy の単体テスト |
| S12 | **ログによる個人情報漏洩** | 高 | 中 | 本文をサーバーに送らない設計、許可リストロガー、`console.*` 禁止 | ログ出力のテスト |
| S13 | **第三者スクリプトへの情報流出**（解析タグ・外部フォント・CDN） | 中 | 低 | MVP は外部解析ツールなし、フォントは自己ホスト、CSP で外部接続を `self` に限定 | CSP 違反レポートの確認 |
| S14 | **セッション盗用**（Cookie を盗まれた場合） | 中 | 低 | `__Host-` 接頭辞、Secure、HttpOnly、短い有効期限、連携解除で Google 側トークンも失効 | Cookie 属性テスト |
| S15 | **オープンリダイレクト** | 中 | 低 | ログイン後の戻り先は固定パスのみ（外部 URL を受け付けない） | 戻り先パラメータ改ざんテスト |
| S16 | **sessionStorage の残存データ** | 低 | 中 | 本文は保存しない、候補日時のみ、復元後即削除、30 分で無効 | E2E で削除確認 |
| S17 | **依存パッケージの脆弱性・サプライチェーン攻撃** | 高 | 低 | 依存最小化（googleapis 不使用）、lockfile 固定、`npm audit`、Dependabot | CI で監査 |
| S18 | **アカウント取り違え**（複数 Google アカウント） | 低 | 中 | 同意時に `prompt=select_account` でアカウント選択を表示 | 手動確認 |
| S19 | **フィッシング・なりすまし** | 中 | 低 | 正式ドメインの明示、OAuth 同意画面にアプリ名・ロゴ・ポリシー URL を登録（審査要件） | — |
| S20 | **法令・規約違反**（個人情報保護法、Google API ユーザーデータポリシー） | 高 | 中 | プライバシーポリシーで取得情報・利用目的・保存しないことを明記。Google の「Limited Use」要件に従う | 公開前チェックリスト |
| S21 | **環境設定ミス**（本番で偽 Google を指定、HTTP 配信） | 高 | 低 | `GOOGLE_ENDPOINT_OVERRIDE` は localhost でのみ有効、本番 APP_ORIGIN は https 必須、HSTS | 環境変数検証テスト |
| S22 | **エラーメッセージからの内部情報露出** | 低 | 中 | ユーザーには定型の日本語文言とエラーコードのみ返す | API エラー応答のテスト |
