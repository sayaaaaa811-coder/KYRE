## 承認時にご判断いただきたい事項

| # | 事項 | 提案（推奨） | 代替案 |
|---|---|---|---|
| D1 | リフレッシュトークン | **取得しない**（1 時間ごとに再連携。漏洩時の被害が小さい） | 取得して暗号化 Cookie に保存（再連携不要だが漏洩時の被害が大きい） |
| D2 | Google アカウントのメール取得 | **取得しない**（最小権限。「連携済み」とだけ表示） | `openid email` を追加し、どのアカウントと連携中か表示 |
| D3 | 照合対象カレンダー | **primary のみ**（最小権限） | 追加スコープで複数カレンダー対応（MVP 後） |
| D4 | 日時解析 | **ルールベースのみ**（AI 不使用・費用ゼロ・本文を外部送信しない） | 失敗時のみ AI 解析（有料・同意必須） |
| D5 | 代替案の間隔 | **間引きなし**（近い順に 3 件） | 代替案同士を 30 分以上離す |
| D6 | 「来週」の解釈 | **月曜始まりで解釈し、要確認バッジを付ける** | 確認なしで確定 |
| D7 | 解析・計測ツール | **MVP では導入しない** | 匿名イベントのみ計測（導入時に再承認） |
| D8 | ホスティング | Phase 5 で改めて相談（Vercel Hobby は非商用限定のため利用目的の確認が必要） | Cloudflare / Cloud Run 等 |
